Relate — sqlite-wasm demo

This page demonstrates initializing the sql.js WASM DB, applying the schema, importing assets/users.json into the users table, and persisting the DB to IndexedDB.

Before using this demo, run npm install sql.js and ensure sql-wasm.wasm is served at /node_modules/sql.js/dist/sql-wasm.wasm, or adjust the locateFile path in the script below.
